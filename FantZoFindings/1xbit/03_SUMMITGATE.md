### Domain Cloaking
`fastsecurepay88.xyz` root page contains JS that checks hostname:
```javascript
if (hostname === "summitgateglobal.com" || 
    hostname === "fastsecurepay88.xyz" || ...)
```
Redirects to `fastsecurepay.asia` if accessed directly — cloaking layer.

## Category: Payment Page Analysis

`/gateway` renders a bilingual (English/Chinese) payment status page:
- **Title:** "Payment Blocked"
- **Message:** "Repeated unpaid orders detected — payment access restricted"
- **Chinese:** 支付权限已受限
- Includes language tab switcher (EN/中文)
- This is the page customers see when their order is blocked
- With a **valid order token/ID**, this page would show UPI QR codes or bank details

### `/order` Behavior
- GET and POST both return **empty 200** regardless of params
- Accepts `application/json` and `application/x-www-form-urlencoded`
- No cookies set, stateless
- Likely needs: `merchant_key`, `amount`, `order_id`, `sign` to return order creation response
- Without valid merchant credentials, silently returns nothing
